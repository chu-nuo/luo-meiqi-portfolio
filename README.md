# 罗美琪 AI 产品经理作品集

React、Vite 与原生 CSS 构建的个人作品集，面向 AI 产品经理和产品经理岗位。

## 本地运行

```powershell
npm install
npm run dev
```

默认访问 `http://127.0.0.1:5173/`。

## 构建

```powershell
npm run build
npm run preview
```

构建脚本会生成 `dist/404.html`，用于 GitHub Pages 子路由刷新回退。

## 公开边界

- 仓库不包含原始 PRD、问答手册、测试账号或后台凭据。
- 健康对话原图、旧简历和内部材料保存在仓库外，不参与构建。
- GitHub Pages 是公开静态托管，不能为已下发到浏览器的内容提供访问级加密。
